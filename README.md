# PoseNet - Human Pose Detection

## Project Overview
This project demonstrates human pose detection in a web browser
using HTML, CSS, JavaScript, and the PoseNet model.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Browser-based user interface
- Human pose estimation
- Visual display of detected body keypoints

## Project Structure
- `index.html` - Web page structure
- `style.css` - Page styling
- `sketch.js` - Pose detection logic

## Purpose
The purpose of this project is to explore browser-based
human pose estimation using web technologies.
